# Initial engineering audit

Performed on the existing `webapp` checkout before implementation. Scope: every web source module, server routes and background jobs, Mongo schemas, scaler JSON and six ONNX artifact inventories, package manifests/locks, Vite/lint configuration, Docker/Nginx and README. Secret-bearing lines were redacted during inspection; tracked environment files were inventoried by path only. Binary model weights cannot establish training provenance.

| Area           | Finding                                                                                                                                        | Decision                                                                                                                                                            |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Credentials    | Embedded Gemini credential; root `.env`, `.env.production`, `backend/.env` tracked                                                             | Remove credential-bearing server implementation; leave env files untouched for owner cleanup. No automatic env loading. See SECURITY.md.                            |
| Authorization  | First `/portfolios` route shadows authenticated duplicate; all portfolio/settings/alert mutations trust caller IDs                             | Remove remote persistence and all account endpoints from guest demo. No Mongo connection or migration.                                                              |
| Verification   | `Math.random` codes, unbounded temporary users, no TTL/attempt budget                                                                          | Remove registration/email/JWT surface, including fallback JWT secret.                                                                                               |
| Portfolio      | Sale proceeds subtracted from cost basis; backdated sells, edits and deletions can invalidate history; missing fee accounting                  | Shared chronological decimal ledger, weighted average basis, replay validation on every mutation.                                                                   |
| Market data    | 30 ticker calls, weekly/monthly calls in series, 120 more OHLC calls per table request, overlapping 15-second jobs                             | One batched ticker call, one shared candle resource per pair/interval, demand-driven bounded cache.                                                                 |
| Symbols/quotes | Retired symbols, fixed EUR/GBP/TRY conversions; volume presented as cap                                                                        | Small explicit asset registry, USDT consistently labeled; exchange quote volume only.                                                                               |
| Resilience     | Unbounded requests/retries absent; unprotected force refresh; DB scans in price refresh                                                        | Timeouts, single retry, provider cooldown, deduplication, bounded stale responses and cache, request limits. No force refresh route.                                |
| Charts         | Incorrect candle property mapping; fabricated OHLC from close series; inconsistent interval/filter behavior                                    | Use provider OHLCV directly, UTC milliseconds and completion flag. Charts share data across modes.                                                                  |
| Models         | Six ONNX artifacts, scaler files but no training code/data/evaluations/feature contracts; lag requests exceed 1000-bar limit for daily horizon | Preserve binaries/scalers as quarantined provenance only; remove runtime and six endpoints. Offline Python research pipeline; one explicit disabled prediction API. |
| News           | Ungrounded current-news prompts, old model/API references, unsafe forced refresh                                                               | Remove legacy generated-news and paid-provider integrations and dependencies.                                                                                       |
| Frontend       | Mixed Axios/fetch origins, repeated context/settings calls, prop mutation, page reloads, unguarded storage parsing                             | Typed schema-validated API client, TanStack Query, local guest state and recoverable storage failures.                                                              |
| Learning       | Useful chart imagery and concepts; some quiz questions ambiguous or incorrect; incompatible editor imports                                     | Preserve educational purpose and historical imagery, replace quiz content and remove unused code editor.                                                            |
| Dependencies   | Server-only email/logging packages in browser, redundant chart packages, unused CSV/logger, heavy ONNX build                                   | Root npm workspace with one lock, smaller maintained dependencies, TypeScript throughout active code.                                                               |
| Deployment     | Node 18/20 images, baked remote IP, inconsistent proxy routing, publicly exposed API/DB assumptions                                            | Node 24 LTS, deterministic multi-stage builds, explicit `/api` proxy, localhost web port only, no DB.                                                               |

The rewrite is warranted for server.js and the coupled frontend: leaving dormant vulnerable route implementations would make accidental reuse easy. Contributor names and legacy ONNX/scaler artifacts remain; Git history is untouched. Browser storage is device-local demo state, not authenticated user storage. No production account migration is attempted.
